A momentum paper-trading bot for pump.fun: it buys bonding curves showing accelerating buy pressure from several distinct wallets, pyramids into strength, and exits on a stop-loss, trailing stop, fade, or time limit, with tiny probe round-trips keeping it above the 20-coin guardrail.

## Run it

```sh
node main.ts
```
