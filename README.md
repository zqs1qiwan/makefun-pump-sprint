A paper-trading bot for pump.fun: it buys only strong fresh launches (at least 10 SOL of real reserves in the first 3 slots, 2–3 distinct non-creator buyers, creator buy at most 1 SOL, creator not sold), pyramids into runners with up to two 0.50 SOL add-on tranches while the price holds up, and exits at +40% take-profit, −8% stop-loss, a 15-slot hold limit, or immediately if the creator sells. Tiny 0.01 SOL probe round-trips top the count up to the 20-coin guardrail.

## Run it

```sh
node main.ts
```
